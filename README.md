# Форсаж — картинг-центр

Учебный проект КР №2. Студент: **Узеев Руслан Исмаилович**, группа **ЭФБО-05-25**.

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Практическая работа 9

Создана отдельная реализация на Bootstrap 5.3.8. Главная содержит hero, преимущества, популярные программы и адаптивную сетку `container`, `container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `col-lg-6`, `g-4`, `gx-4`, `gy-5`. На этапе №9 CSS и JS Bootstrap подключены через CDN; custom.css — после фреймворка.
