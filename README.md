# Форсаж — картинг-центр

Учебный проект КР №2. Студент: **Узеев Руслан Исмаилович**, группа **ЭФБО-05-25**.

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Практическая работа 9

Создана отдельная реализация на Bootstrap 5.3.8. Главная содержит hero, преимущества, популярные программы и адаптивную сетку `container`, `container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4`, `col-lg-6`, `g-4`, `gx-4`, `gy-5`. На этапе №9 CSS и JS Bootstrap подключены через CDN; custom.css — после фреймворка.

## Практическая работа 10

Созданы `catalog.html`, `product.html`, `order.html` и единая навигация. Используются `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `breadcrumb` и `table-responsive`. Bootstrap JS Bundle обеспечивает работу меню, окна выбора и FAQ.

## Подключение Bootstrap

В финальной версии Bootstrap 5.3.8 подключён **локально**, без CDN: `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`. `css/custom.css` идёт после него. Лицензия MIT сохранена в `vendor/bootstrap/LICENSE`. Скопированы официальные файлы из ранее подготовленного локального дистрибутива Bootstrap; удалены лишь ссылки на необязательные карты исходников. Npm, Node и сборка для запуска сайта не требуются.

## Простое оформление

В текущей версии используются обычные заголовки, светлый фон, стандартные кнопки `btn-dark` и карточки Bootstrap. Убраны декоративные номера, крупный рекламный заголовок и дополнительная промосекция. В custom.css осталось четыре понятных правила: фон, активная ссылка, ссылка пропуска навигации и видимый фокус. Данные и функции каталога и формы сохранены.

## Запуск

Скачайте проект вместе с историей Git:

```sh
git clone https://github.com/enjo1si/kr2-bootstrap-shop.git
cd kr2-bootstrap-shop
git status
```

Откройте **эту папку** в VS Code через File → Open Folder… . Откройте `index.html` браузером через Finder либо используйте расширение Live Server автора Ritwick Dey: правый щелчок на index.html → Open with Live Server. После изменения файла нажмите ⌘S. Для просмотра без Live Server обновите браузер.

Если GitHub недоступен, запасной вариант — восстановление из `forsazh-history.bundle` по [инструкции](docs/START-HERE.md#запасной-вариант-из-архива). Обычный ZIP исходников не содержит `.git`.

## Самостоятельные доработки по №11

- Локальный Bootstrap, отсутствие внешних шрифтов, изображений и запросов для работы сайта.
- Две дополнительные страницы: трассы и карты, о центре.
- Два комбинируемых фильтра — возраст и опыт. Счётчик результатов и сообщение при пустой выборке.
- Сценарий каталог → описание/модальное окно → форма переносит программу через `?program=...`.
- Калькулятор итоговой стоимости: цена программы × число участников (1–4).
- Проверка соответствия возраста программе и обязательного опыта для гоночного заезда.
- Дата от завтра до 60 дней вперёд; получасовые начала, длительность программы учитывается при закрытии в 21:00. Реальную занятость расписание не учитывает.
- Проверка имени, e-mail, телефона и согласия; текстовый итог заявки, скрытие устаревшего результата, сброс формы.
- Адаптивная сетка, доступные подписи полей, видимый фокус и переход к основному содержимому, читаемая таблица.

Эти доработки расширяют сценарий посетителя. Для высокой оценки студент должен изучить код, объяснить решения и самостоятельно проверить работу. Автоматической гарантии балла нет.

## Ограничения

Сайт учебный. Сервер, отправка заявок, оплата и настоящее бронирование не реализованы. Персональные данные не сохраняются в браузере и не отправляются по сети: вводите вымышленные. Цены, возрастные условия, размеры трасс и расписание демонстрационные. Настоящие контакты и фото центра не предоставлены. SVG-изображения — учебная схема и иллюстрация, а не фотографии действующей трассы.
