# Форсаж — учебный сайт картинг-центра

Учебный проект КР №2. Студент: **Узеев Руслан Исмаилович**, группа **ЭФБО-05-25**.

HTML, CSS, JavaScript и локальный Bootstrap. Бэкенда, API и сборки нет.

## Запуск
Откройте `index.html` в браузере. Для общего localStorage между страницами рекомендуется статический хостинг (например, GitHub Pages) или встроенный предпросмотр IDE. Некоторые браузеры ограничивают общее хранилище для файлов `file://`.

## Возможности
- Шесть программ с отдельными карточками, описаниями, ценами и формой выбора.
- Поиск по программам и разделам сайта, с состояниями пустого запроса и отсутствия результатов.
- Светлая и тёмная темы: анимация 650 мс, сохранение выбора, поддержка reduced motion.
- Учебный чат с автоматическими ответами, быстрыми вопросами, историей и очисткой переписки.
- Учебный личный кабинет без пароля: имя, почта, редактирование, выход и история заявок.
- Валидация бронирования, расчёт цены, сохранение заявок без повторного добавления при повторной проверке.

## Ограничения учебной версии
Никакие заявки и сообщения не отправляются на сервер. Настоящей регистрации, авторизации и связи с оператором нет. Один локальный профиль на браузер; вводите вымышленные данные. localStorage не предназначен для секретов. Очистка данных браузера удаляет профиль, историю и настройки.

## Проверка вручную
1. В каталоге должно быть 6 карточек; фильтры возраста и опыта должны менять количество.
2. «Марафон» и «Заезд с другом» открывают правильные описания и доступны в бронировании.
3. Найдите «детская», затем несуществующее слово; проверьте результаты и пустое состояние.
4. Переключите тему в обе стороны и перейдите на другую страницу.
5. В чате спросите о ценах, закройте и откройте его, затем очистите переписку.
6. Войдите с вымышленными именем и почтой, отредактируйте профиль и выйдите.
7. Заполните учебную заявку на будущую дату; после входа в кабинет проверьте историю.

Исходный дизайн и контент сохранены. Bootstrap находится в `vendor/bootstrap`, лицензия приложена.
