## Git и передача

Подготовлены независимые от «ХвостКом» начальный коммит и три учебных этапа с ветками `feature/bootstrap-grid-page`, `feature/bootstrap-components`, `fix/kr2-final-check`. Технический автор подготовительных коммитов — Project preparation. В первоначальном комплекте main содержала начальное состояние, чтобы последовательно оформить PR каждого этапа.

Подтверждён вход в аккаунт enjo1si и создан репозиторий [enjo1si/kr2-bootstrap-shop](https://github.com/enjo1si/kr2-bootstrap-shop). Учебные ветки опубликованы. Проверены настоящие PR:

- [PR №1](https://github.com/enjo1si/kr2-bootstrap-shop/pull/1), `feature/bootstrap-grid-page → main` — объединён, merge-коммит `f7c603b`.
- [PR №2](https://github.com/enjo1si/kr2-bootstrap-shop/pull/2), `feature/bootstrap-components → main` — объединён, merge-коммит `63ecb5c`.

Финальные исправления, простое оформление и эта документация передаются из `fix/kr2-final-check` в `main` отдельным PR. Его создание и объединение не объявляются завершёнными в этом отчёте: фактический статус доступен во вкладке [Pull requests](https://github.com/enjo1si/kr2-bootstrap-shop/pulls). После его объединения итоговую версию следует получать из main. GitHub Pages не включён.

Переносимый bundle проверен через git bundle verify: полная история корректна. Выполнено тестовое клонирование в отдельную папку, восстановлены учебные ветки и main, рабочая папка чистая. Основной путь получения проекта теперь — клонирование GitHub-репозитория; bundle оставлен запасным вариантом.
