# Соответствие практическим №9–11

Основа — те же предоставленные методички, по которым готовился «ХвостКом». Здесь предметная область — каталог заездов и обучения картинг-центра «Форсаж». Каталог услуг допускается заданием.

| Требование | Где реализовано |
|---|---|
| Отдельный проект `kr2-bootstrap-shop` | Свой каталог и переносимая Git-история, не история «ХвостКом» |
| №9: CDN-подключение, главная, hero, преимущества, программы | Ветка feature/bootstrap-grid-page |
| №9: container, row, адаптивные col, отступы | Главная и итоговые страницы |
| Обязательные index/catalog/product/order.html | Все четыре файла сохранены с требуемыми именами |
| Navbar и единая навигация | Каждая страница; product выделяет раздел «Заезды» |
| Card, btn, badge, alert | Главная, каталог, описание, форма |
| Modal, JS Bundle | Окно выбора на главной и в каталоге |
| Form-control, form-select, input-group, form-check | order.html |
| Дополнительный компонент | Accordion на product.html |
| Таблица, цена, параметры, кнопка | product.html, tracks.html |
| Custom.css после Bootstrap | head каждой страницы |
| Локальный Bootstrap для доработки №11 | vendor/bootstrap/css и js |
| Самостоятельные страницы | tracks.html, contacts.html |
| Улучшенный каталог | Четыре программы, два совместных фильтра, пустая выборка |
| Улучшенный сценарий заявки | Перенос программы, возраст, опыт, участники, цена и время |
| README, автор/группа, доработки и проверки | README и docs |
| Ветки и настоящие PR | PR №1 (сетка) и №2 (компоненты) объединены; финальные изменения принимаются через fix/kr2-final-check → main. Ссылки и статус — в VERIFICATION.md |
| Сдача ссылкой на репозиторий | Создан репозиторий https://github.com/enjo1si/kr2-bootstrap-shop; перед сдачей проверить итоговый main и объединение PR |

КР №3 из конца методички №11 не относится к этой реализации. Гарантия максимального балла не даётся: оцениваются объяснение, самостоятельная работа и демонстрация.
